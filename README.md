# 동물 인형뽑기

HTML 파일 하나로 만든 웹 인형뽑기 미니게임입니다. 설치 없이 `index.html`을 브라우저로 열면 바로 플레이할 수 있어요.

- `index.html` — 게임
- `intro.html` — 10초짜리 게임 소개 모션그래픽

## 게임 방법

집게를 좌우로 움직여 동물 인형 위에 맞춘 뒤 뽑기를 누르세요. 집은 인형은 왼쪽 위 출구로 옮겨져 점수가 됩니다.

- 토끼 · 곰 · 고양이 · 강아지 · 돼지 · 병아리: 각 50점
- 펭귄(가끔 1개만 등장): 100점
- 코인 10개로 **300점**을 모으면 클리어!

## 조작

| 동작 | 키보드 | 화면 |
|---|---|---|
| 집게 이동 | ← → | 아래 왼쪽·오른쪽 버튼(누르고 있기), 게임 화면 끌기 |
| 뽑기 | 스페이스, ↓ | 가운데 뽑기 버튼 |

## 미디어 파일 (선택)

`index.html`과 같은 폴더에 아래 파일을 넣으면 자동으로 사용합니다. 없어도 게임은 정상 동작해요.

- `poster.png` — 시작 화면 포스터
- `music.mp3` — 배경 음악(반복)
- `ending.mp4` — 클리어 영상
